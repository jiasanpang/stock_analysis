# 选股策略详细说明

> 本文档描述 AI 智能选股模块的量化筛选策略体系，包括各策略的参数、评分逻辑、过滤流程及配置方式。

---

## 一、系统架构概览

### 1.1 两阶段流程

| 阶段 | 职责 | 输出 |
| ---- | ---- | ---- |
| **Stage 1 量化筛选** | 全市场 → 多策略并行 → 合并候选池 | ~30 只候选（可配置多策略时更多） |
| **Stage 2 AI 精选** | 候选池 + 市场情报 + 筹码 → LLM 精选 | 1–5 只推荐（宁缺毋滥） |

### 1.2 多策略并行设计

- 配置 `PICKER_STRATEGIES` 可指定多个策略（逗号分隔）
- 基本面筛选**共享**，之后**按策略分叉**，各自独立跑动量、量价、打分、后过滤
- 各策略的候选池**按代码合并**：相同股票取并集策略标签、取最高分
- 前端支持「合并」与「按策略对比」两种视图，便于对比各策略选股差异

## 二、筛选流程

### 2.1 整体流程

```
全市场 → 基本面(PE/ST/停牌) → [按策略分叉]
    ↓
    ├─ 策略A: 动量 → 量价 → 打分Top30 → 乖离率 → 连板 → 连涨 → 健康回踩 → B浪
    ├─ 策略B:  ...
    ├─ 策略C:  ...
    └─ 策略D:  ...
    ↓
合并去重(按代码) → 候选池
```

### 2.2 共享层：基本面过滤

| 条件 | 说明 |
| ---- | ---- |
| ST/退市 | 名称含 ST、*ST、退市、N、C 排除 |
| ETF | 排除 51/52/56/58/15/16/18 前缀 |
| PE | 0 < PE ≤ pe_max（策略参数）；`PICKER_ALLOW_LOSS=true` 时允许 PE≤0 |

### 2.3 共享层：量价过滤（策略参数）

| 条件 | 说明 |
| ---- | ---- |
| 量比 | > volume_ratio_min（策略参数） |
| 换手率 | 1% ~ 15%（可配置 TURNOVER_MIN/TURNOVER_MAX） |
| 成交额 | 市值 < 100 亿：> 3000 万；≥ 100 亿：> 1 亿 |

### 2.4 后过滤层（共享逻辑，策略参数）

| 过滤 | 说明 |
| ---- | ---- |
| **乖离率** | 当前价相对 MA5 乖离率 > max_bias_pct 排除；龙头可豁免（仅突破策略启用，60d>15%、今日 2–7%、量比>1.5、换手 2–8%） |
| **连板** | 近 5 日 2+ 次涨停排除（主板 9.5%、创业板/科创板 19%） |
| **连涨** | 连续上涨天数 > max_consecutive_up_days 排除 |
| **健康回踩** | 6 层过滤：缩量检查、均线多头、回调幅度、距20日高点≥3%、价格在MA20之上、距MA10≤3% |
| **B 浪风险** | 可选：疑似 B 浪反弹（反弹 35–65%，低点 2–14 日前）排除 |

## 三、策略详解

### 3.1 涨停回踩 (buy_pullback，LUP 引擎)

**策略逻辑**：事件驱动。先对"涨停日"做质量检验建立锚点池（tushare
`limit_list_d`，缺失时日线推导兜底），再在涨停日后 **5 个交易日**观察窗内
等待缩量回踩确认，出现五大形态之一才出票。纯 tushare 数据，不依赖新闻/LLM。

**涨停日质检（红线否决）**：

| 红线 | 默认 | 说明 |
| ---- | ---- | ---- |
| 首封时间 | ≤ 14:00 | 偷袭板否决；9:35 前 +8 分、10:30 前 +4 分 |
| 炸板次数 | ≤ 5 | 0 次（封板坚决）+6 分 |
| 连板数 | < 5 | ≥5 板为高位末尾，否决 |
| 换手率 | 1% ~ 40% | 10–20% 甜蜜区 +6 分 |
| 涨停日放量 | 1.0 ~ 8.0 倍 | 缩量板/爆量出货否决；1.5–3 倍 +4 分 |
| 启动前涨幅 | 5% ~ 100%（60日低点起） | 30–70% 主升中段 +5 分；累计涨幅 >150% 否决 |
| 大盘 | 上证当日 > -1.5% | 暴跌日孤板否决 |

> 教科书最优区间实测占比 <4%（2026-02..05，4142 个涨停样本），故只作
> 加分项排序优先级，不作硬否决，否则零召回。

**五大确认形态**（缩量：确认日量 ≤ 涨停日 60%；放量阴线：阴线日量 ≥ 0.9 倍涨停日量即判出货）：

- 三阴不破阳（92 分）/ 龙回头（90）/ 回踩5日线（85）/ 回踩10日线（82）/ 假阴真阳（75）
- 兜底形态"缩量横盘"（66 分，默认关闭）：`LUP_ALLOW_CONSOLIDATION=1` 启用，
  要求缩量 ≤ `LUP_CONSOL_VOL_MAX`(0.45)、收阳且站上涨停实体中轴。回测显示按
  五形态 0.6 标准放宽会使 PF 2.73→1.16，故仅以更严标准提供 opt-in 兜底。

**买卖点与出场**（`LUP_EXIT=1`，3 天超短风格）：

- 结构化止损 = max(涨停K最低价, 理想买价×0.96)；理想买价锚定 MA5/MA10
- +10% 减半仓 → 回吐至 <5% 或断 MA10/ATR×2.5 清仓；破 MA20−3% 直接清仓
- 3 日无 +5% 时间止损；最长持仓 3 天；单票仓位 ≤15%；R/R<2.0 自动剔除

**门控与开关**：

- MarketGuard：LUP 下上证需高于 MA20 ≥ **-2%**（`BUY_PULLBACK_GATE_PCT`，
  旧链路仍为 +2%）
- `LUP_ENABLED=0` 一键回滚旧横截面趋势回踩链路（60d 涨幅 5–40%、MA 多头、
  缩量回踩等参数见 git 历史 v3.x 文档）
- 各阈值支持 `LUP_{KEY}` 环境变量覆盖，形态可用 `LUP_PATTERN_*=0` 单独关闭

**回测证据**（2026-02-02 ~ 05-15，65 交易日，top_n=5）：11 笔 / 9 个出票日，
胜率 63.6%，平均 +1.53%，**PF 2.31**，最大回撤 3.86%。放宽缩量红线
（0.6→0.8 / 0.9→1.2）会使笔数升至 68 但 PF 跌至 0.95 —— 缩量纪律是本
策略的核心 alpha 来源，不建议放宽。

### 3.2 底部反转 (bottom_reversal)

**策略逻辑**：大跌后企稳，左侧或早期反转。要求缩量确认底部、放量反转信号。

| 参数 | 值 | 说明 |
| ---- | - | ---- |
| 60日涨跌幅 | -25% ~ **-5%** | 跌够多且仍处于底部区间（收紧上限，排除已反弹较多的标的） |
| 当日涨幅 | **1%** ~ 5% | 要求明确反弹信号（收紧下限，排除弱势横盘） |
| 量比 | > **0.7** | 降低门槛，底部缩量也接受 |
| 乖离率 | ≤ 6% | 底部时多为负乖离 |
| 均线 | 不要求 | 底部往往未形成多头 |
| 最大回调（B浪） | **61.8%** | 斐波那契 B 浪过滤（收紧，排除 B 浪反弹陷阱） |
| 缩量检查 | **启用** | `require_volume_shrink=True`，回调缩量确认底部 |
| 连涨天数 | ≤ 3 | 不追连涨 |

**评分逻辑**（趋势 + 动量 + 量能 + PE + 市值 + **增强信号**）：

- **趋势**：60d 越不负面越高分；-25% 得 0，0 得 20，0–10% 得 20–25
- **60日跌幅深度加分**（新增）：跌幅 ≤ -15% 额外 +5，≤ -20% 额外 +8，深度超跌反弹空间更大
- **动量**：0–3% 最高 20 分；3–5% 15 分；5%+ 10 分
- **缩量→放量转折信号**（新增）：近期缩量后当日放量（量比 > 1.5），额外 +5，确认资金入场
- **反转K线形态**（新增）：出现锤子线、吞没阳线等经典反转形态，额外 +3
- **量比**：≥ 1.5 满分；≥ 0.7 部分分
- **换手**：1–10% 满分
- **PE**：8–35 满分
- **市值**：50–500 亿 加 5 分

### 板块强度过滤（Sector Strength Filter）

在基础过滤之后、策略过滤之前，通过行业板块强度排名筛选候选股。

**原理**：强势板块中的回踩/突破机会质量更高，弱势板块的技术形态信号可靠性低。

**判断逻辑**：
1. 获取全部行业板块当日涨跌排名（数据源：东方财富/AkShare）
2. 取涨幅前 N%（默认30%）的板块为强势板块
3. 获取强势板块的所有成分股代码
4. 候选股必须在强势板块成分股中才能进入后续策略筛选

**按策略区分**：
| 策略 | 板块过滤 | 原因 |
|------|---------|------|
| buy_pullback | 启用 | 强势板块回踩反弹概率更高 |
| bottom_reversal | 跳过 | 超跌反弹可出现在任意板块 |

**配置参数**：
| 环境变量 | 默认值 | 说明 |
|---------|--------|------|
| `PICKER_SECTOR_FILTER` | `true` | 启用/关闭板块过滤 |
| `PICKER_SECTOR_TOP_PCT` | `30` | 取涨幅前N%的板块 |

#### 板块数据加载优化

- **启动预加载**：服务启动后自动后台加载板块排名和成分股数据，首次选股直接命中缓存
- **定时刷新**：每 50 分钟后台自动刷新，保证缓存不过期
- **并发获取**：10 线程并发获取成分股，300 秒超时保护
- **重试容错**：东方财富 API 不稳定时自动重试 3 次（5/10/15 秒退避）
- **安全降级**：板块数据获取失败时跳过板块过滤，不影响选股主流程

## 五、健康回踩过滤详解

健康回踩用于区分「健康回踩到支撑位」与「下跌通道」与「半空中下跌途中」，包含 **6 层检查**：

> **设计思路**：真正的健康回踩应满足三个条件：①从高点回落足够距离（不是追高）；②仍处于上升趋势中（未跌破MA20）；③回落到均线支撑位附近（MA10附近）。通过 6 层过滤，精准定位「回踩到支撑位准备反弹」的时机，排除「下跌通道中的反弹」和「半空中无支撑的下跌途中」。

### 5.1 Check 1: 缩量回调（可选）

- 策略 `require_volume_shrink=True` 时启用
- 当日为跌或平盘（change_pct ≤ 0）且量比 ≥ 1.3 时排除（1.0–1.3 视为轻微放量，仍可接受）
- **底部反转策略启用**（`require_volume_shrink=True`），回调缩量确认底部

### 5.2 Check 2: 均线多头排列（可选）

- 策略 `require_ma_bullish=True` 时启用
- 要求 MA5 > MA10 > MA20
- 仅买回踩要求

### 5.3 Check 3: 回调幅度限制

- 公式：`retracement = (近10日高点 - 当前价) / (近10日高点 - 近10日低点)`
- 仅当 `current_pullback > 0`（即当前价低于近 10 日高点）时检查
- 若 retracement > max_retracement_pct，排除
- 底部反转设为 100%， effectively 不限制（因底部时 retracement 常接近 100%）

### 5.4 Check 4: 距20日高点最小距离（`min_pullback_from_high_pct`）

- 仅 buy_pullback 启用（默认 3.0%）
- 当前价距20日最高点的跌幅必须 ≥ 3%，排除追高
- 公式：`(20d_high - current_price) / 20d_high × 100 ≥ min_pullback_from_high_pct`
- 其他策略设为 0（不启用）

### 5.5 Check 5: 价格在 MA20 之上（`require_price_above_ma20`）

- 仅 buy_pullback 启用（默认 True）
- 当前价必须在 MA20 之上，跌破 MA20 说明已进入下跌通道，排除
- 防止误把「下跌通道中的反弹」当作「健康回踩」

### 5.6 Check 6: 距 MA10 不超过指定距离（`max_distance_above_ma10_pct`）

- 仅 buy_pullback 启用（默认 3.0%）
- 当前价与 MA10 的距离不超过 3%，确认价格在支撑位（MA10）附近
- 公式：`abs(current_price - MA10) / MA10 × 100 ≤ max_distance_above_ma10_pct`
- 排除「半空中下跌途中」——价格远离所有均线支撑，无着力点

## 六、B 浪风险过滤（可选）

排除疑似 B 浪反弹（反弹 35–65% 后可能进入 C 浪下跌）：

- 回溯 20 日
- A 浪跌幅 ≥ 5%
- 反弹幅度在 35–65%（斐波那契 B 浪区）
- 低点出现在 2–14 日前

可通过 `PICKER_ENABLE_B_WAVE_FILTER` 开关。

## 七、配置与使用

### 7.1 环境变量

```bash
# 选股策略，逗号分隔，默认 buy_pullback
PICKER_STRATEGIES=buy_pullback,bottom_reversal

# 是否允许亏损股
PICKER_ALLOW_LOSS=false

# 是否启用 B 浪过滤
PICKER_ENABLE_B_WAVE_FILTER=true
```

### 7.2 API

```http
POST /api/v1/picker/recommend
Content-Type: application/json

{
  "picker_strategies": ["buy_pullback", "bottom_reversal"]
}
```

响应包含 `screened_pool`（合并候选池）和 `screened_pool_by_strategy`（按策略分组的候选池）。

### 7.3 前端

- 选股页可勾选策略组合
- 结果页支持「合并」与「按策略对比」两种视图，便于对比各策略选股差异
